There is a teleporter located on each of the points $$$1, 2, \dots, n$$$. At point $$$i$$$, you can do the following:</p><ul> <li> Move left one unit: it costs $$$1$$$ coin. </li><li> Move right one unit: it costs $$$1$$$ coin. </li><li> Use a teleporter at point $$$i$$$, if it exists: it costs $$$a_i$$$ coins. As a result, you teleport to point $$$0$$$. Once you use a teleporter, you <span class="tex-font-style-bf">can't</span> use it again. </li></ul><p>You have $$$c$$$ coins, and you start at point $$$0$$$.
